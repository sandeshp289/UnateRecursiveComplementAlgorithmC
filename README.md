# UnateRecursiveComplementAlgorithmC

Description:

    Unate Recursive Complement Algorithm in C/C++

Input Files:

    urca.c                           : C/C++ code

    part1.cubes                      : Input file (for e.g. part1.cubes) containing the boolean function in text format in the form of cubes

Output Files:

    part1.out.cubes                  : Output file in text format, containing the complement of the input function

   
Compilation:

    g++ urca.c
    
Execution:

    ./a.out part1
